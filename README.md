🌤️ Live Weather Dashboard

📌 Project Overview

Live Weather Dashboard is a responsive weather website that displays real-time weather information and a 5-day forecast for any searched city.

The application uses the Open-Meteo API to retrieve weather data dynamically.

✨ Features

- Search weather by city name
- Display current temperature
- Weather conditions with icons
- Feels-like temperature
- Humidity information
- Wind speed details
- 5-day weather forecast
- Input validation and error handling
- Responsive mobile-friendly design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- Open-Meteo Weather API

⚙️ Key Concepts

- Asynchronous JavaScript
- API integration
- JSON data handling
- Dynamic DOM manipulation
- Error handling using try/catch/finally
- Responsive web design

🌐 API Used

Open-Meteo API

Weather API: https://open-meteo.com/

Geocoding API: https://open-meteo.com/en/docs/geocoding-api

🚀 How to Run

1. Clone or download this repository.
2. Open the index.html file in a browser.
3. Enter a city name in the search box.
4. Click Search to view live weather information.
